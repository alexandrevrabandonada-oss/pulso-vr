# data/interim

Área temporária para conversão de DBC/DBF, limpeza mecânica e harmonização de
layouts. Todo artefato deve ser reconstruível a partir de `data/raw/`.

As séries `sih_morbidity_*.csv` são contagens agregadas do SIH por residência,
com seis grupos respiratórios do TabNet e três geografias. Elas não são taxas
nem contagens de pessoas únicas.
