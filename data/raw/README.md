# data/raw

Arquivos originais baixados de fontes públicas ou recebidos por parceria. Esta
pasta é imutável: não editar, renomear ou sobrescrever arquivos. Cada arquivo
deve possuir um sidecar `<arquivo>.sha256` e uma linha em
`metadata/extraction_log.csv`.

Não armazenar aqui dados pessoais, bases restritas, credenciais ou tokens.
